# TeacherProblem — База скриптов для учителя (Segoe UI Theme + PostgreSQL Admin Panel)

База готовых проверенных речевых скриптов и алгоритмов общения для молодых и практикующих педагогов. Помогает экологично и оперативно решать сложные ситуации с учениками, родителями и школьной администрацией.

---

## 🚀 Подробное руководство по локальному запуску проекта

Для запуска проекта на вашем компьютере потребуется установленный [Node.js](https://nodejs.org/) (версия 18 или новее) и, опционально, [PostgreSQL](https://www.postgresql.org/) (если вы планируете подключить локальную базу данных).

### 1. Клонирование / Скачивание репозитория
Откройте терминал (или командную строку / PowerShell) и перейдите в папку с проектом:
```bash
cd teacher-problem
```

### 2. Установка зависимостей
Установите необходимые пакеты с помощью пакетного менеджера `npm`:
```bash
npm install
```

## 🗄️ Настройка базы данных PostgreSQL

Проект поддерживает работу с **PostgreSQL** для хранения пользователей и педагогических скриптов.

1. **Создайте базу данных в PostgreSQL:**
   ```sql
   CREATE DATABASE teacher_problem;
   ```
2. **Инициализируйте структуру таблиц и начальные данные:**
   Выполните SQL-скрипты из корня проекта:
   ```bash
   psql -U postgres -d teacher_problem -f schema.sql
   psql -U postgres -d teacher_problem -f seed.sql
   ```
3. **Настройте переменные окружения:**
   В корне проекта создайте файл `.env` (или настройте переменные окружения):
   ```env
   PORT=3001
   PGUSER=postgres
   PGPASSWORD=postgres
   PGHOST=localhost
   PGPORT=5432
   PGDATABASE=teacher_problem
   ```
   *(Примечание: Если база данных PostgreSQL не запущена, сервер автоматически переключается в резервный режиме (in-memory mode), сохраняя полную работоспособность приложения).*

## 💻 Запуск проекта

Для полной работы приложения запустите бэкенд API сервер и фронтенд сервер разработки.

### Шаг A. Запуск бэкенд API сервера (Express + PostgreSQL)
В первом окне терминала выполните:
```bash
node server.js
```
Сервер запустится на адресе `http://localhost:3001`.

### Шаг B. Запуск фронтенд клиента (Vite)
Во втором окне терминала выполните:
```bash
npm run dev
```
Фронтенд запустится на адресе `http://localhost:3000` (или `http://localhost:5173`).

Откройте ссылку в браузере.

## ✨ Реализованный функционал
- **Дизайн в стиле Segoe UI (Modern Fluent Theme):** Чистый, адаптированный под рабочую среду интерфейс на базе Segoe UI.
- **Приветственный экран:** Описание возможностей и форма входа под учетной записью учителя.
- **Верхнее горизонтальное меню:** Выпадающие подменю «Материалы», «Инструменты», «Помощь» и «Панель администратора».
- **Кнопка брендинга:** Переключает на главную страницу в любой момент.
- **Профиль учителя (в правом верхнем углу):**
  - Интерактивный аватар с иконкой `+` для загрузки/смены фотографии.
  - Выпадающее меню при наведении (**Сменить фото**, **Настройки**, **Панель администратора**, **Выход**).
- **Панель администратора (Admin Panel):**
  - Добавление новых учителей в базу данных PostgreSQL.
  - Редактирование существующего профиля, роли и должности.
  - Удаление аккаунтов с подтверждением.
- **База скриптов из PostgreSQL:**
  - Фильтрация по категориям («Ученики», «Родители», «Администрация», «Коллеги»).
  - Мгновенный поиск по ключевым словам.
  - Копирование ответа в один клик.
