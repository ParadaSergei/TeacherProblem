# TeacherProblem — База скриптов для учителя

База готовых проверенных речевых скриптов и алгоритмов общения для молодых и практикующих педагогов. Помогает экологично и оперативно решать сложные ситуации с учениками, родителями и школьной администрацией.

---

## 🚀 Подробное руководство по локальному запуску проекта

Для запуска проекта на вашем компьютере потребуется установленный [Node.js](https://nodejs.org/) (версия 18 или новее).

### 1. Клонирование / Скачивание репозитория
Откройте терминал (или командную строку / PowerShell) и перейдите в папку с проектом:
```bash
cd teacher-problem
```

### 2. Установка зависимостей
Установите необходимые пакеты с помощью пакетного менеджера `npm`:
```bash
npm install
```

### 3. Запуск в режиме разработки (Local Dev Server)
Для запуска локального сервера разработки выполните команду:
```bash
npm run dev
```
После выполнения команды в терминале появится ссылка на локальный адрес, обычно:
`http://localhost:5173` или `http://localhost:3000`.

Откройте эту ссылку в любом браузере для работы с сайтом.

## 🛠 Дополнительные команды

### Сборка проекта для продакшена (Production Build)
Чтобы собрать оптимизированную финальную версию проекта:
```bash
npm run build
```
Скомпилированные файлы будут находиться в папке `dist/`.

### Предпросмотр продакшен-сборки
Для локального запуска и проверки итоговой сборки из папки `dist/`:
```bash
npm run preview
```

## ✨ Реализованный функционал
- **Дизайн в стиле Segoe UI (Modern Fluent Theme):** Чистый, адаптированный под рабочую среду интерфейс.
- **Приветственный экран:** Описание возможностей и кнопка входа под учетной записью учителя.
- **Верхнее горизонтальное меню:** Разворачивающиеся подменю «Материалы», «Инструменты», «Помощь».
- **Кнопка с логотипом и названием:** Возвращает на главную страницу в любой момент.
- **Профиль учителя (в правом углу):**
  - Интерактивный аватар с иконкой `+` для загрузки/смены фотографии.
  - Плавный выпадающий список при наведении с пунктами **Сменить фото**, **Настройки** и **Выход**.
- **База скриптов:** Фильтрация по категориям, мгновенный поиск и копирование готового текста ответа в буфер обмена.
